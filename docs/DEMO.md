# Демонстрация на 3–4 минуты

Цель показа: продемонстрировать работающий прототип и объяснить границы выводов. Новые запросы к LLM для демонстрации не нужны.

## Перед выступлением

1. Открыть `demo/replay.html` двойным щелчком в локальной копии репозитория. Страница автономная: данные включены в неё, сервер и ключ не нужны. GitHub показывает исходный HTML; для интерактивного показа открыть локальный файл.
2. Выбрать «Новости + общение», профили 11, раунд 0.
3. Открыть терминал в корне проекта и подготовить команду:

```powershell
.\.venv\Scripts\python.exe scripts/demo.py --offline
```

Если окружение ещё не создано: Python 3.12+, `python -m venv .venv`, затем `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.

## План показа и готовые формулировки

### 0:00–0:30. Задача

«Я проверял реализуемость первой идеи — изменения коллективных предпочтений. В небольшом сценарии шесть участников выбирают, развивать в библиотеке цифровой доступ или печатные книги. У них разные исходные позиции и доверие источнику. Они получают новость и сообщения соседей».

### 0:30–1:15. Агенты и наблюдения

Показать шесть узлов, запустить проигрывание раундов. Выбрать агента и показать его дословный ответ.

«Здесь показаны сохранённые результаты реальной bonsai2-27b. Новых обращений к модели сейчас нет. В проекте используются EntityAgent, ListMemory, ObservationToMemory и ConcatActComponent из Concordia. Среда, сеть и расписание раундов написаны в проекте. Каждый раунд использует снимок предыдущего состояния».

### 1:15–2:00. Проверка устойчивости

Выбрать «Только общение», раунд 4. Переключить профили 11, 22, 33. Для точного сравнения с контролем можно показать консольную сводку: `python scripts/demo.py`.

«В первом наборе общение увеличило дисперсию относительно контроля на 0,0176. В двух других оно уменьшило её на 0,0227 и 0,0331. Поэтому первый результат нельзя объявлять универсальной закономерностью. Точное повторение одной конфигурации воспроизводилось, а перенос между профилями — отдельная проверка».

### 2:00–2:40. Память и состав промпта

Вернуть профили 11. Сравнить «Новости + общение» с «Окно 4, без исходного поля» в раунде 4.

«Базовая дисперсия — 0,3189. При длинном окне без поля initial_opinion — 0,2011. Меняются два явно зафиксированных параметра; отдельно проверены и промежуточные сочетания. Это результат одного факторного опыта, а не доказательство психологического механизма».

### 2:40–3:15. Настоящий локальный запуск

Выполнить подготовленную команду с `--offline`. Она запускает шесть настоящих агентов Concordia на один раунд с математической заглушкой.

«Это новый технический запуск без сети. Он подтверждает работу компонентов. Результаты с реальной LLM показаны отдельно в сохранённых журналах, поэтому я не смешиваю заглушку и языковую модель».

### 3:15–3:50. Вывод и ограничения

«Минимальный прототип реализован. Выполнено 534 реальных LLM-запроса, сохранены ответы и конфигурации, проходят 27 тестов. Основная сложность теперь — интерпретация: эффекты зависят от профилей и промпта. Роли фиксированы, модель одна, собственной истории аргументов пока нет, сравнения с людьми ещё не проводились. Следующий шаг — переставить роли между позициями и проверить общение без численных самооценок».

## Запасной вариант без браузера

```powershell
.\.venv\Scripts\python.exe scripts/demo.py
```

Команда печатает короткую сводку по реальным сохранённым результатам. Для неё достаточно Python; зависимости Concordia нужны только для `--offline`.
